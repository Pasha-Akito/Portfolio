### For each selected project, what was your role and what should visitors notice?

Only include claims supported by the repository or your explicit answer.

Pasha built essentially all of each shortlisted public project himself.

- **Arla:** A full-stack alumni social network. Its React and Redux frontend
  includes authentication, registration, profiles, posts and friend feeds,
  interest communities, and course-based alumni discovery. Its JavaScript
  backend uses Express, Apollo/GraphQL, and Neo4j; authentication uses Auth0.
- **Bongard Problem Image Generator:** A Python text-to-image transformer for
  generating Bongard Problem pairs, created for Pasha's master's thesis,
  *Thinking in Images: Analysing Concept Learning in Neural Networks by
  Generating Bongard Problems*. The repository includes reproducible datasets,
  model configuration, training and image-generation tools, result analysis,
  and the thesis paper.
- **BlackJack-C:** An early C implementation of Blackjack accompanied by a
  public YouTube walkthrough. It demonstrates Pasha's interest in building and
  sharing software from the beginning of his studies.
- **aia:** A Python command-line assistant for asking a local Ollama model a
  one-shot question. It handles setup, VRAM-aware model discovery, model
  management, streamed answers, unloading and bounded recovery, while avoiding
  logging prompts and answers by default. Pasha built it as a practical harness-
  engineering and agentic-development exercise.
